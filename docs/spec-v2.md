## 1 项目概述

### 1.1 设计目标

1. 整车整备质量**≤50kg**，最大设计总质量**300kg**，可平稳通过水泥地面、碎石缓坡、30°户外坡道，**可连续攀爬标准民用楼梯至7层楼高**（单级台阶高≤150mm，踏面深≥260mm）；
2. 依靠左右中轮转速差滑移转向，可原地自旋（限松软/泥泞地面），硬质水泥地仅允许大半径差速转弯；
3. 中轮采用**加长短摆臂（浮动行程130mm）**被动浮动补偿地形；前后轮采用**弹性联动拉杆（替代原刚性拉杆）**，在平路保持重卡式均载，在爬楼大冲击时允许前/后摇臂独立缓冲，化解俯仰累积；
4. 车身搭载横向被动差速平衡架，左右地形高差自动平衡，防止侧翻；
5. 全部结构件采用板材/型材切割成型，无任何焊接工序，所有连接依靠螺栓、止口、压板锁紧；
6. 伺服电机固定在主车体不随摆臂运动，通过滚子链将动力传递至摆臂上的行星减速机与驱动中轮，不使用万向节；
7. **新增双液压回路**：左右电机后端各驱动一台齿轮泵，两路独立压力输出；**行走/爬楼工况时，液压泵通过卸荷阀零压空转（等效断开）；液压作业工况时，行走系统抱闸锁死，全力供油**。两者不同时使用，功率完全解耦。

## 2 整车总体方案与工作原理

### 2.1 整车布局侧视逻辑

1. 车体主梁为铝合金方管型材，全部拼接处采用L型角码+内衬定位套+螺栓锁紧；车顶增设**X型对拉钢丝绳（带花篮螺丝）**，抵消差速转向时的菱形变形；
2. 车身左右各一套独立行走悬架：
   - 中部：**加长短摆动臂总成（摆臂长380mm，浮动行程130mm）**，伺服电机锁死在主梁，链条传递动力给摆臂末端行星减速机+中驱动轮；
   - 前部、后部：对称L型直角摇臂，中间**弹性联动拉杆**（套筒+预压弹簧+调节螺母）连接，平路呈刚性均载，大冲击时允许独立缓冲；
3. 车身顶部横向布置被动差速平衡架，连接左右两套侧悬架总成，左右地面高度不一致时自动杠杆平衡，减小车体侧倾角；
4. 前后四轮纯从动，无电机、无转向节，依靠地面侧向滑动跟随车身转向；
5. **新增**：电机后端通过梅花联轴器驱动齿轮泵，泵出口并联卸荷电磁阀；行走/爬楼模式时阀得电导通（零压卸荷），液压模式时阀断电关闭（建压），同时中轮机械抱闸锁死。

### 2.2 三大核心机构工作原理（升级版）

#### 2.2.1 纵向均载直角摇臂（弹性联动化改造）

单侧前、后各一套90°L型直角摇臂，摇臂拐角通过销轴螺栓铰接在侧主梁；两根摇臂内侧端用**弹性拉杆**螺栓连接。

- **平路模式**：拉杆内预压弹簧（刚度200N/mm，预压缩5mm）锁死，前后摇臂呈刚性联动，前轮上抬→后轮同步下压，载荷均等（重卡模式）；
- **爬楼冲击模式**：前轮撞上台阶棱角产生剧烈上抬，瞬时力超过预紧力时，弹簧被压缩，允许前摇臂**独立上摆+15mm缓冲行程**，同时后轮不会即刻强制下压，大幅缓解原刚性联动导致的"俯仰角累积"现象；
- 所有铰接销轴两端配垫片+开口挡圈螺栓锁紧，无焊接。
- **调节功能**：通过旋转拉杆端部调节螺母，可针对不同楼梯坡度（不同层高）微调预紧力。

#### 2.2.2 中轮浮动短摆臂 + 滚子链传动（核心约束实现 + 行程扩容）

约束：电机固定车体、减速机+车轮随摆臂浮动、不用万向节。

实现手段：
1. 摆臂回转铰接销轴为空心轴，电机输出轴从空心销轴中心穿过，电机完全固定在主梁；
2. 主动链轮安装在电机轴（回转中心不动），从动链轮安装在摆臂末端减速机输入轴；
3. 主、从动链轮中心距永久固定（摆臂绕主动链轮轴线摆动），链条长度恒定，无需万向补偿角度；
4. 从动链轮安装座开设腰形调节孔（调节范围±5mm），用于补偿链条长期磨损后的松弛；
5. **摆臂加长升级**：摆臂长度由原250mm延长至**380mm**，铰点位置上移，最大垂直浮动行程由50mm提升至**130mm**（摆角±20°），完美包络标准楼梯踢面（150mm）高度差；
6. 摆臂与主梁之间装配预压弹簧（刚度**6N/mm**，预压缩**25mm**）及上下限位螺栓。平路中轮锁死近似刚性；过台阶时地面反力压缩弹簧，中轮被动抬升130mm，极大提升越障高度。

#### 2.2.3 横向被动差速平衡架（防侧倾，沿用V1）

车身中轴线顶部安装一根横向平衡梁，梁中点铰接车体，两端通过球头螺栓分别连接左右侧悬架上支点；左侧地面抬高→平衡梁左端上升、右端下压，左右侧悬架反向小幅摆动，车体侧倾角减半，避免单侧车轮悬空。

### 2.3 差速滑移转向原理（无转向舵机，沿用V1）

左右两侧伺服电机完全独立电控驱动：
1. 直行：左右电机同转速同方向；
2. 大半径转向：左右电机同向，设置转速差（适用于所有地面）；
3. 原地转向：左右电机等转速反向旋转（仅限沙土、泥泞、松软地面）；

前后从动轮无转向功能，依靠地面侧向滑动完成转向动作。

### 2.4 行走/液压互斥工作原理（新增）

- 左右电机均为**双出轴**：前出轴→行走传动链；后出轴→梅花联轴器→齿轮泵。
- 整车设**"行走/爬楼模式"**与**"液压作业模式"**，由驾驶面板旋钮切换，互锁逻辑如下：

| 模式 | 卸荷阀状态 | 泵端负载 | 行走抱闸 | 应用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **行走/爬楼** | 得电导通（卸荷） | 零压空转，阻力≈0.05~0.1N·m | 松开 | 平地、坡道、爬楼梯 |
| **液压作业** | 失电关闭（建压） | 输出压力能 | 锁死中轮 | 驻车后驱动终端执行器 |

## 3 分系统机械结构详细设计（全螺栓、无焊接）

### 3.1 主车体框架总成（沿用V1，增补抗扭加强）

**材料与成型**：6061铝合金方管40×40×3mm，数控切割定长；所有拼接角位配铝合金L型角码、平板连接板。

**连接工艺（无焊接）**：
1. 方管端面预钻通孔，角码两侧钻沉头螺栓孔；
2. 方管对接端面内嵌钢制定位衬套（传递剪切力），M8螺栓仅提供压紧力，不承受侧向剪切；
3. M8内六角螺栓+平垫+弹垫锁紧所有拼接缝，螺栓涂抹乐泰243螺纹胶；
4. 横梁与纵梁交叉处使用U型抱箍螺栓夹紧加固；
5. **新增抗扭加强**：车顶安装4个吊耳，张紧两根**X型交叉不锈钢钢丝绳（直径3mm）+花篮螺丝**，施加200N预紧力，将矩形框架变为两个三角形桁架，大幅提升差速转向时的抗菱形变形能力，增重仅0.8kg；
6. 车身顶部预留安装座（钢板切割支座），螺栓固定差速平衡架铰接点。

### 3.2 中轮浮动短摆臂传动总成（升级：加长至380mm，行程130mm）

**零件清单（全部螺栓装配）**：
1. **摆臂主体**：10mm厚铝板线切割成型，一体折弯，**长度380mm**，铰点孔位重新计算；
2. 空心铰接销轴：45#钢车削，贯穿主梁支座，两端M10螺栓+挡圈限位；
3. 电机固定支座：钢板切割，4颗M8螺栓锁紧在主梁；
4. 主动链轮：平键固定在伺服电机输出轴，轴端锁紧螺母限位；
5. 08B滚子链+从动链轮：从动链轮平键连接行星减速机输入法兰；从动链轮座开设腰形调节孔（±5mm）；
6. 行星减速机（**减速比30:1**，额定输出扭矩≥300N·m）：法兰端面4颗M6螺栓锁紧在摆臂末端安装台；
7. 中轮轮毂：减速机输出轴平键+锁紧螺母固定；
8. **缓冲弹簧组（新参数）**：刚度**6N/mm**，预压缩**25mm**，最大压缩至**155mm**（对应130mm行程）；上下限位螺栓重新调整至±20°摆角限位。

**关键尺寸更新**：
- 摆臂铰点至轮心距离 = **380mm**
- 主动链轮中心至从动链轮中心距离 = **180mm**（恒定）
- 最大浮动行程垂直投影 = **130mm**

### 3.3 前后L型直角摇臂总成（升级：弹性联动拉杆替代刚性拉杆）

1. L型摇臂：8mm铝板切割90°拐臂一体件；拐角开孔穿铰接销轴；
2. 铰接支座：钢板切割支座，螺栓锁在侧主梁；销轴两端螺栓限位；
3. **弹性联动拉杆（新设计）**：
   - 外部套筒（45#钢，壁厚3mm），两端带内螺纹；
   - 内部压缩弹簧（钢丝直径5mm，中径25mm，刚度200N/mm，自由长度60mm）；
   - 两端调节螺杆（M12×1.5）连接前后摇臂内侧；
   - 螺母调节预压缩量，平路预压5mm（锁死），爬楼冲击时压缩量≤15mm（缓冲限位）；
4. 从动轮支架：摇臂外端螺栓锁紧轮轴座，200mm从动轮自由转动；
5. 辅助扭簧：挂接摇臂与主梁，提供向下预紧力，保证车轮贴地。

### 3.4 横向被动差速平衡架总成（沿用V1）

1. 平衡梁：8mm厚长条铝板；中点开孔铰接车顶中心支座；
2. 中心铰接销轴：M12螺栓+双推力轴承，允许梁左右摆动；
3. 两端球头拉杆：螺纹可调长度，下端螺栓连接左右侧悬架上支点；
4. 限位缓冲橡胶块：螺栓固定车顶，限制平衡梁最大摆动行程±15°。

### 3.5 车轮总成（沿用V1）

1. 中驱动轮：φ300橡胶防滑轮，轮毂带平键槽，适配行星减速机输出轴；
2. 前后从动轮：φ200橡胶轮，内置30204圆锥滚子轴承（成对背对背安装），轮轴螺栓锁紧在摇臂端部。

## 4 动力与传动系统参数计算（完整详细版，含60:1新参数）

### 4.1 载荷分配

**计算前提**：六轮左右对称布局，纵向载荷按"中轮承担单侧60%、前后轮合计承担单侧40%"分配。

**满载300kg代入**：
- 整车总重力 G = 300 × 9.8 = **2940 N**
- 单侧总垂向载荷 Fz单 = 2940 / 2 = **1470 N**
- 单侧中轮垂向载荷 Fz中 = 1470 × 0.6 = **882 N**
- 单只前后从动轮垂向载荷 Fz从 = (1470 × 0.4) / 2 = **294 N**

### 4.2 爬楼梯轮端峰值扭矩

采用单轮台阶攀爬力学模型，以台阶棱角为力矩支点。

- 中轮半径 r = 0.15m，标准楼梯极限台阶高度 h梯 = 0.15m
- 因中轮浮动行程由50mm扩至130mm，**有效补偿高度取 h补 = 0.12m**，故有效爬高 h = 0.03m

计算结果：
- 力臂 a ≈ **0.09 m**
- 稳态爬楼轮端扭矩 T轮稳 = **79.4 N·m**
- 峰值冲击轮端扭矩 T轮峰 = **198.5 N·m**（安全系数 S=2.5）

> 对比V1：原有效爬高0.12m，扭矩260N·m；现浮动行程增大，峰值需求大幅下降至198.5N·m。

### 4.3 传动减速匹配与伺服电机校核（更新为60:1）

**传动参数**：
- 链传动比 i₁ = 30/15 = **2**
- 行星减速机减速比 i₂ = **30**
- **总减速比 i = 60**
- 传动总效率 η ≈ **0.85**

**电机参数（80TM-04830C10-RHD）**：
- 额定功率 1.5kW，额定转速 3000rpm
- 额定扭矩 4.8N·m，峰值扭矩 9.6N·m

**轮端输出扭矩校核**：
- 轮端额定扭矩 = 4.8 × 60 × 0.85 = **244.8 N·m**
- 轮端峰值扭矩 = 9.6 × 60 × 0.85 = **489.6 N·m**

**校核结论**：
- 爬楼稳态需求79.4N·m < 额定244.8N·m ✅
- 峰值冲击198.5N·m < 额定244.8N·m ✅（**质变：峰值已落入额定区**）

### 4.4 行驶车速与功率校核

- **额定车速** = π × 0.3 × 50 / 60 ≈ **0.785 m/s ≈ 2.83 km/h**
- 轻载超频（3900rpm）≈ **3.67 km/h**
- 5°缓坡需功率 ≈ **372W** << 双侧总额定3kW ✅
- 30°最大爬坡需功率 ≈ **1493W** < 3kW ✅

### 4.5 中轮浮动弹簧参数校核（新参数）

- 预紧力 F₀ = 0.2 × 882 ≈ **176 N**
- 弹簧刚度 k = **6 N/mm**（取值稍软，改善冲击吸收）
- 最大弹簧力 F_max = 6 × (25 + 130) = **930 N**

最大弹簧力略大于中轮载荷882N，在浮动末端起限位缓冲作用。

## 5 液压系统原理与断开控制设计（新增完整章节）

### 5.1 双泵独立回路架构

- **泵组配置**：2台CBN-E300齿轮泵（排量3ml/r，额定压力16MPa），分别由左右电机后端输出轴通过梅花联轴器驱动。
- **油路架构**：每台泵独立构成1路液压油路，两路完全独立，共用4L铝合金油箱。

### 5.2 卸荷阀方案

每台泵出油口并联**二位二通常闭电磁换向阀（DSG-02-2B2，DC24V）**：

| 模式 | 卸荷阀 | 泵端负载 | 行走抱闸 |
| :--- | :--- | :--- | :--- |
| **行走/爬楼** | 得电导通（卸荷） | ≈0.05~0.1N·m | 松开 |
| **液压作业** | 断电关闭（建压） | 输出压力能 | 锁死中轮 |

### 5.3 功率耦合校核

行走时泵端空载功耗 = 0.1 × 3000 / 9550 ≈ **31W**，占电机额定功率仅 **2%**。

### 5.4 互锁逻辑

| 输入（旋钮） | 卸荷阀电磁铁 | 行走电机使能 | 行走抱闸 | 液压输出 |
| :--- | :--- | :--- | :--- | :--- |
| **行走/爬楼** | 得电（导通） | 使能 | 松开 | 无压力 |
| **液压作业** | 断电（关闭） | 禁止使能 | 锁死 | 建压 |

## 10 安全操作规范（强化互锁警告）

1. 最大设计总质量300kg，抬升装配必须双人协作；
2. **爬楼梯必须切换至"行走/爬楼"模式**（卸荷阀得电指示灯亮）。严禁在"液压"模式下爬楼；
3. 爬楼梯全程车速不得超过**0.5m/s**；
4. 切换至"液压作业"模式前，**必须确认车辆已完全停稳**，中轮抱闸锁死后方可建压；
5. 水泥/沥青路面**严禁原地自旋转向**；
6. **模式互锁逻辑参数（卸荷阀与抱闸联动）严禁改动**。
