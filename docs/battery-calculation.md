## 2. 上楼能耗计算

### 2.1 重力势能法（理论最小值）

```
E_势能 = m × g × H
       = 300 × 9.8 × 21.6
       = 63,504 J ≈ 0.0176 kWh
```

这是**绝对物理下限**——实际能耗远大于此。

### 2.2 电机输入功率法（基于 spec §8.1 操作策略）

spec §8.1 给出爬楼时电机负载 **≈3.8 N·m（额定79%）**，转速约 3000rpm。

**单侧电机实际输入功率**:

```
P_单侧 = T × ω = 3.8 × (3000 × 2π / 60)
       = 3.8 × 314.16
       ≈ 1,194 W
```

**双侧总输入功率**: **≈2,388 W**

### 2.3 爬楼耗时估算

按 spec §8.1 操作策略，爬楼限速 ≤0.3~0.4 m/s。取 **0.35 m/s**（实际台阶攀爬速度）。

```
单层梯段长度 ≈ 18级 × 260mm(踏面) = 4.68m
单层耗时 ≈ 4.68 / 0.35 ≈ 13.4秒
8层总爬楼时间 ≈ 13.4 × 8 ≈ 107秒 ≈ 1.79分钟
```

### 2.4 上楼耗电

```
E_上楼 = P_双侧 × t
       = 2,388W × (107/3600)h
       ≈ 0.071 kWh
```

### 2.5 平台转弯能耗

每层平台需转弯调整方向（spec §8.1: "差速转向"），负载约 **1 N·m**，耗时 ~5秒。

```
P_转弯 = 1 × 314.16 ≈ 314W/侧 → 双侧 ≈ 628W
E_转弯 = 628W × (5×7/3600)h ≈ 0.006 kWh  (7次平台转弯，最后一层无需转)
```

### 2.6 上楼总耗电（含安全系数）

| 项目 | 能耗(kWh) | 占比 |
|:-----|:---------:|:----:|
| 梯段攀爬 | 0.071 | 92% |
| 平台转弯 | 0.006 | 8% |
| **上楼小计** | **0.077** | — |
| × 安全系数(启动冲击/摩擦损耗) | ×1.5 | — |
| **上楼实际耗电** | **≈0.116 kWh** | — |

## 3. 下楼能耗计算

### 3.1 下楼工况分析

下楼时电机主要承担**制动控制**（伺服电机再生制动或电阻耗能），而非主动驱动。

| 模式 | 说明 | 能耗特征 |
|:-----|------|---------|
| **再生制动** | 电机发电，能量回馈电池 | **省电**——部分能量回收 |
| **电阻耗能** | 电能消耗在制动电阻上 | **不回收**——但不耗电 |
| **主动驱动(低速下行)** | 电机正转但低功率控制速度 | **耗电**——约上楼30-50% |

**保守估算**: 下楼按上楼的 **40%** 计（考虑部分再生制动 + 重力辅助）。

```
E_下楼 = E_上楼 × 0.4 ≈ 0.116 × 0.4 ≈ 0.046 kWh
```

### 3.2 往返总耗电

| 项目 | 能耗(kWh) |
|:-----|:---------:|
| 上8层 | 0.116 |
| 下8层 | 0.046 |
| **往返合计** | **0.162 kWh** |

## 4. 电池容量需求计算

### 4.1 最小电池容量（理论）

```
E_电池 ≥ E_总 / (DOD × η_系统)

其中:
- DOD (放电深度): 磷酸铁锂建议 ≤0.85
- η_系统 (BMS+线损效率): ≈0.92
```

```
E_电池 ≥ 0.162 / (0.85 × 0.92)
       ≥ 0.162 / 0.782
       ≥ 0.207 kWh
       ≥ 48V × Ah → Ah ≥ 0.207 / 48 ≈ 4.3 Ah
```

### 4.2 实际选型推荐（考虑冗余）

| 场景 | 安全系数 | 所需容量(kWh) | 对应Ah (48V) | 备注 |
|:-----|:--------:|:-------------:|:------------:|:-----|
| 仅上楼8层 | ×1.5 | 0.174 | **3.6 Ah** | 极限最小 |
| 上+下8层(往返) | ×1.5 | 0.243 | **5.1 Ah** | 推荐底线 |
| 上+下8层 + 平路机动 | ×2.0 | 0.324 | **6.8 Ah** | **推荐** |
| 充足冗余(含额外作业) | ×3.0 | 0.486 | **10.1 Ah** | 充裕方案 |

## 6. 结论

### 推荐方案: **DC48V / 10Ah 磷酸铁锂电池**

| 指标 | 值 |
|:-----|:---|
| **电池规格** | DC48V / 10Ah LiFePO4 |
| **能量** | 0.48 kWh |
| **重量** | ~9 kg |
| **往返能耗(上+下8层)** | ~0.162 kWh (含安全系数) |
| **往返后剩余电量** | **(0.48 - 0.162) / 0.48 ≈ 66%** ✅ |
| **可重复往返次数** | **约 3 次** (按DOD≤85%计) |
| **价格参考** | ¥1,200-1,500 |

### 是否够用？

**✅ 够。** 48V/10Ah 磷酸铁锂电池可以完成满载300kg爬8层往返楼梯，往返后剩余约66%电量。即使按"上下各8层 = 总共爬升16层高度"的极端理解，也能完成约2.5次往返。

### 更轻方案（如重量敏感）

如果必须控制整车重量，**48V/5Ah** (~4.5kg) 是理论底线——刚好够单次上+下8层，但余量极小，不建议。

## 附: 电流校核

| 工况 | 功率(W) | 电压(V) | 电流(A) |
|:-----|:-------:|:-------:|:-------:|
| 爬楼稳态(双侧) | 2,388 | 48 | **49.8 A** |
| 峰值冲击(双侧峰值) | 3,000 | 48 | **62.5 A** |
| 平台转弯(双侧) | 628 | 48 | **13.1 A** |

- 10Ah LiFePO4 电池通常支持 **1C~3C持续放电** = 10~30A持续电流
- **⚠️ 49.8A > 30A (3C极限)**——短时爬楼可接受，但需确认电池支持 **≥5C脉冲放电**
- **建议**: 选型时明确要求 **持续放电 ≥50A**（约5C倍率），或选用动力型磷酸铁锂电池（支持10C）
