# 双电机双液压回路6轮被动摇臂式全地形入户底盘工程设计需求规格说明书

## 一、项目定义

**项目名称**：双电机双液压回路 6 轮被动摇臂式全地形入户底盘工程设计

**设计定位**：参考火星车被动摇臂悬架构型，兼顾平地行驶、坡面通行、楼梯攀爬三类核心工况，作为动力机甲承载底盘，完成从货车卸载至室内入户的全流程作业

**设计输入约束**：
- 满载整车总质量 ≤ 50kg
- 车轮直径 300mm
- 采用指定伺服电机 + 驱动器 + 旋变解码板硬件方案

**标称性能指标**：
- 标称平地行驶速度 5km/h
- 理论最大爬坡度 ≥ 30°
- 可连续攀爬标准民用楼梯至 7 层楼高

**核心设计目标**：基于选定硬件与性能指标，完成双电机独立驱动 + 双路独立液压源动力架构、6 轮中驱被动摇臂底盘的完整工程设计，输出可落地的机械构型、动力匹配、液压回路方案，并完成全工况性能校核与边界验证。

---

## 二、底盘行走系统设计要求

- **轮系布局**：整车采用左右对称 6 轮布局，单侧沿纵向依次布置前轮、中轮、后轮，共 6 个车轮；所有车轮直径统一为 300mm
- **驱动方案**：仅左右两侧中轮为主动驱动轮，前轮与后轮为无动力从动轮，随地形被动滚动；左右中轮采用双电机独立驱动架构，两侧动力完全解耦
- **悬架构型**：采用火星车式被动摇臂悬架，前后轮分别安装于独立摇臂末端；摇臂与底盘主体铰接，可绕铰接点自由被动摆动，仅通过地形接触力实现路面自适应贴合，不设置主动姿态调节执行机构
- **转向方式**：依靠左右中轮的转速差实现差速转向，不设置独立转向轮组；前后轮随整车运动被动适配转向轨迹
- **传动接口**：每侧中轮轮轴与对应侧行星减速机输出端直连，为单侧行走动力输出接口
- **质量约束**：整车满载总质量（含底盘结构、动力单元、液压系统、搭载负载）设计上限不超过 50kg

## 三、动力与传动系统设计方案

### 3.1 伺服电机单元（共 2 台，左右对称独立布置）

| 参数 | 值 |
|------|-----|
| 型号 | 80TM-04830C10-RHD 永磁同步伺服电机 |
| 额定功率 | 1.5 kW |
| 额定电压 | DC 48 V |
| 额定转速 | 3000 rpm |
| 最高空载转速 | 3900 rpm |
| 额定扭矩 | 4.8 N·m |
| 瞬时峰值扭矩 | 9.6 N·m |
| 额定电流 | 37 Arms |
| 瞬时最大电流 | 74 Arms |
| 极数 | 20 极 |
| 结构特性 | 双出轴，法兰式安装；反馈元件为旋转变压器 |
| 单台重量 | 2.85 kg |
| 功能分配 | 一端输出行走动力，另一端同步驱动液压齿轮泵 |

### 3.2 行走传动链路（左右各 1 套，共 2 套）

- **传动路径**：电机输出端 → 减速比 50:1 行星减速机 → 同侧中轮驱动轴
- **功能**：独立输出单侧行走与转向所需的扭矩与转速，通过左右电机转速差实现整车前进、后退、差速转向及调速

### 3.3 伺服驱动与反馈系统（共 2 套，一一对应）

**伺服驱动器**
| 参数 | 值 |
|------|-----|
| 型号 | BCPC-09050-OPE 系列直流伺服驱动器 |
| 供电范围 | 18~90 VDC |
| 连续输出电流 | 50 Arms |
| 峰值输出电流 | 100 Arms（6s） |
| 控制模式 | 位置、速度、转矩三闭环 |
| 指令接口 | 脉冲、模拟量、CANopen、RS485 |

**旋变解码板**
| 参数 | 值 |
|------|-----|
| 型号 | RS 系列旋变解析卡（匹配 20 极电机，增量式输出） |
| 功能 | 将电机旋转变压器信号转换为增量式 ABZ 正交编码信号 |
| 供电 | 18~90 VDC |
| 激励频率 | 10 KHz |
| 励磁电压 | 2.4 VACrms |

### 3.4 液压传动链路（双泵双独立回路）

- **泵组配置**：共 2 台液压齿轮泵，分别由 2 台电机的非行走端输出轴同步驱动
- **油路架构**：每台齿轮泵独立构成 1 路液压油路，整车共 2 路独立压力输出回路
- **配套元件**：共用 1 套集成液压油箱，承担油液存储、散热与双回路系统补油功能
- **设计范围**：完成双泵源参数匹配、双回路原理设计、油箱容积与散热设计；核算液压负载波动对行走端动力的耦合影响，终端液压执行机构不在本次设计范围内

## 四、全流程核心工况与设计性能要求

整车作业完整流程：**从货运车厢经坡道下行 → 平地行驶 → 户外小坡通行 → 进入楼道 → 楼道内直行与 90° 转弯 → 攀爬楼梯 → 通过房门进入室内**

### 核心工况设计要求

| 工况 | 要求 |
|------|------|
| **平地行驶** | 硬质水平路面稳态直行，标称 5km/h；双电机负载均衡、系统效率与行驶平顺性 |
| **车厢卸载坡道** | 适配标准货运车厢卸载坡道上下行；姿态稳定、摇臂摆角余量、制动/牵引能力、无倾覆 |
| **坡面行驶** | 户外连续坡面上下行，最大爬坡 ≥ 30°；牵引力裕度、双电机扭矩分配、驻坡保持 |
| **楼梯攀爬** | 适配标准民用楼梯连续上下攀爬至 7 层楼高；台阶通过高度、踏面适配性、全轮接地、倾覆安全裕度、电机热校核 |
| **楼道通行与转向** | 适配标准民用楼道内直行与 90° 直角转弯；最小转弯半径、转向侧移量、宽度适配 |
| **房门通过** | 适配标准民用房门通道通过；整车宽度适配、常规门槛通过能力 |

## 五、设计交付成果

1. **底盘机械构型设计方案**：整车三维布局方案、摇臂悬架参数设计、轮位与轴距布置、尺寸包络与通过性设计
2. **动力传动系统匹配设计**：行星减速机参数校核、轮端扭矩/转速匹配计算、双电机差速转向策略适配、全工况动力负载校核
3. **液压系统原理设计**：双齿轮泵参数选型匹配、双独立回路原理图、油箱容积与散热设计、电机双端功率分配与耦合影响分析
4. **全工况性能校核报告**：运动学通过性校核、动力学负载校核、倾覆安全裕度计算、电机/驱动器热负载校核
5. **关键部件选型确认清单**：基于设计结果确认的减速机、齿轮泵、油箱等核心部件的参数规格清单
