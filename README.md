# 六轮双驱全地形入户底盘

> **版本**: v0.2.0 (V2.0 设计定稿) | **状态**: ✅ 设计完成，待投产

**核心构型**：固定车身伺服电机 + 滚子链传动 + 加长浮动摆臂中轮 + 前后弹性联动直角摇臂 + 横向被动差速平衡架 + 纯差速滑移转向 + 双液压回路（行走/液压互斥）

**工艺要求**：全程无焊接，全部螺栓锁紧装配

---

## 📋 整车核心参数

| 项目 | V2.0 参数 |
| :--- | :--- |
| **整车整备质量（空载）** | ≤50kg（含底盘、双电机、双泵、油箱、电池） |
| **最大设计总质量（满载）** | 300kg |
| 车轮布局 | 六轮对称：左前、左中、左后 / 右前、右中、右后 |
| 中驱动轮直径 | 300mm |
| 前后从动轮直径 | 200mm |
| **中轮浮动行程** | **130mm**（摆臂380mm，±20°） |
| 越障能力 | ≤120mm 台阶平稳通过；**极限 150mm 单级台阶；连续爬楼梯至 7 层** |
| 转向方式 | 左右中轮差速滑移转向（无舵机） |
| 驱动电机 | 80TM-04830C10-RHD，1.5kW/侧，DC48V |
| **总减速比** | **60:1**（链传动2:1 × 行星减速机30:1） |
| **额定车速** | **≈2.83 km/h**（3000rpm）；轻载超频 ≈3.67 km/h（3900rpm） |
| **轮端额定扭矩** | **244.8 N·m** |
| 传动路线 | 固定伺服电机→滚子链→行星减速机(30:1)→中驱动轮 |
| 悬架形式 | 纵向：L型直角摇臂+**弹性联动拉杆**；横向：被动差速平衡架 |
| **液压系统** | 双齿轮泵(CBN-E300)，双独立回路，共用4L油箱；**卸荷阀实现行走/液压互斥** |

## 🔧 技术栈

- **驱动电机**: 80TM-04830C10-RHD 永磁同步伺服 (1.5kW/侧, DC48V)
- **减速机**: 单级行星, 30:1, ≥300N·m
- **传动链**: 08B-1 滚子链 (主动15齿 → 从动30齿)
- **液压泵**: CBN-E300 齿轮泵 (3ml/r, 16MPa) × 2
- **卸荷阀**: DSG-02-2B2 二位二通常闭电磁阀 (DC24V) × 2
- **油箱**: 4L 铝合金散热翅片
- **结构材料**: 6061铝合金方管 40×40×3mm
